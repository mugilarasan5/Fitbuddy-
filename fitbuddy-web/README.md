# FitBuddy Web

A responsive React + Vite frontend for the FitBuddy AI Fitness Planner. It includes onboarding, deterministic AI-crafted 7-day plan generation, workout check-ins, feedback-based plan revisions, progress tracking, and a local coach view.

## Run locally

This app is developed in the Replit monorepo under artifacts/fitbuddy. Run it there with the workspace Vite workflow.

The original FastAPI implementation remains at the repository root.
